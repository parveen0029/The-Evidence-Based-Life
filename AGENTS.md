# AGENTS.md

This repository contains the complete text and tooling for *The Evidence-Based Life*.

- **Modifying this book** (adding/editing rules, updating content, modifying build tools): All editorial standards and contribution guidelines are detailed in [CLAUDE.md](CLAUDE.md). Read the guidelines completely before making changes. The file is named `CLAUDE.md` for historical reasons, but applies universally to any AI agent or human contributor.
- **Using this book to answer questions** (e.g., whether to take an action, assessing ROI, choosing between options, emergency first steps, claiming statutory benefits, verifying legal boundaries): Follow the instructions in [skills/life-decision-guide/SKILL.md](skills/life-decision-guide/SKILL.md). Retrieve the relevant rule before formulating an answer, and always cite the exact chapter and rule number. For installation instructions in other directories or tools, see [skills/life-decision-guide/README.md](skills/life-decision-guide/README.md).
