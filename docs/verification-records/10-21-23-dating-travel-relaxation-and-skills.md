# Verification of records: Section 10 expanded + Sections 21, 22, 23 added

Verification date: 2026-09-07. There are 35 new items in this round (section 10 +8, section 21 10, section 22 10, section 23 7), the total number of the book is 274 → 309.

The method is consistent with previous rounds: English literature uses Europe PMC REST (`search?query=TITLE:"..."&resultType=core`) to retrieve the original text of the title and abstract; psychology journals not included in PubMed use Crossref (`api.crossref.org/works?query.bibliographic=`) to retrieve the title, Semantic Scholar(`api.semanticscholar.org/graph/v1/paper/DOI:…`) gets the abstract. Chinese laws and regulations are located using the JSON interface of the State Council Policy Document Library (`sousuo.www.gov.cn/search-gov/data?t=zhengcelibrary`), and then go to the original text page to check the tags one by one. Laws enacted by the National People's Congress are not in this library, and the full text reprinted from the official website of the Supreme People's Procuratorate is used instead.
